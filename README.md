# 52,000答の迷路 v5 true maze

## 今回の方針

- 一本道ではなく、42×42セルの分岐迷路です。
- 52題を部屋に分けず、全回答パネルをひとつの巨大迷路の床・壁に割り当てています。
- 床も壁も回答パネルで覆う設計です。
- ブラウザが落ちないよう、近くの面だけ実際の文字テクスチャとして生成します。遠くの面も回答パネル割当済みで、近づくと表示されます。
- 壁抜けを防ぐため、壁とは別に当たり判定を入れています。

## 開き方

このフォルダで以下を実行してください。

```bash
python -m http.server 8000 --bind 0.0.0.0
```

PCでは `http://localhost:8000` を開きます。
スマホでは同じWi-Fiに接続し、`http://PCのIPアドレス:8000` を開きます。

## 操作

- WASD：移動
- マウス：視点移動
- Shift：速歩
- F：ランダム移動
- E / クリック：正面の回答パネルを読む
- Q：足元を見る
- スマホ：左スティック移動、右画面ドラッグ視点移動

## 注意

完全なゲームエンジンではなく、WebGLの試作です。スマホでは機種によって重くなる場合があります。
