# 52,000答の迷路 v3

`odai(1).zip` の52個のdocxから回答を抽出して作ったWebアプリ試作です。

## 中身

- `index.html`：Webアプリ本体
- `ogiri_all.json`：52題・51,996回答の統合データ
- `data_report.json`：抽出件数・欠番チェック

## 操作

PC:

- WASD：移動
- マウス：視点移動
- Shift：速歩
- F：ランダムな場所へ移動
- N / P：次・前のお題へ移動
- クリック：正面のパネルを読む

スマホ:

- 左スティック：移動
- 右側ドラッグ：視点移動
- 読む：正面のパネルを読む
- 下を見る：床を見る
- ランダム：ランダムな場所へ移動

## 開き方

`index.html` は `ogiri_all.json` を読み込むので、直接ダブルクリックでは動かない場合があります。
その場合は、このフォルダで以下を実行してください。

```bash
python -m http.server 8000 --bind 0.0.0.0
```

PCでは `http://localhost:8000` を開きます。
スマホで見る場合は、PCと同じWi-Fiに接続し、PCのローカルIPを使って `http://<PCのIPアドレス>:8000` を開きます。

GitHub Pages / Vercel / Netlify に置けばURLだけで見られます。

## データ注意

抽出結果は52題・51,996回答です。以下の4ファイルで1件ずつ欠番がありました。

- ちょっとだけ不謹慎なことを言ってください.docx：496が欠番
- プラネタリウムの雰囲気をぶち壊した彼氏.docx：622が欠番
- 半年滞在した無人島に何かメッセージを残してください.docx：299が欠番
- 道端でわざと死んでいるフリをして.docx：790が欠番

「巨大なミシン…」と「天使猟…」は、元ファイル内で10回答ごとのお題反復がなかったため、文脈が消えないよう全パネルにお題ヘッダーを表示しています。現在のv3では全お題の全パネルにお題ヘッダーを表示しています。
