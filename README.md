# 52,000答の迷路 v4

v3の問題点だった「52題が別部屋」「壁抜け」「壁が埋まっていない」を直すための試作です。

## 変更点

- 52題を部屋に分けず、5200個の10回答パネルを1本の連続した蛇行迷路に配置しました。
- 壁と床の両方にパネルを敷き詰めています。
- 見える壁とは別に当たり判定用の壁を入れ、壁抜けを防いでいます。
- 全5200パネルを一度に描画せず、現在地付近だけ読み込むことで軽くしています。
- ミシン・天使猟を含め、全パネルにお題ヘッダーが出ます。

## 開き方

`index.html` を直接開くより、フォルダ内で下記を実行してください。

```bash
python -m http.server 8000 --bind 0.0.0.0
```

PCなら `http://localhost:8000` を開きます。
スマホで見る場合は、PCと同じWi-Fiにつないで、スマホから `http://PCのIPアドレス:8000` を開きます。

## 操作

- WASD：移動
- マウス：視点移動
- Shift：速歩
- F：ランダム地点へワープ
- クリック：正面のパネルを読む
- スマホ：左スティックで移動、右側ドラッグで視点移動
